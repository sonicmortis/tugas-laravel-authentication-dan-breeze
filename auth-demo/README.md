## Instruksi Cara Menjalankan Project
Ikuti langkah-langkah di bawah ini untuk menjalankan proyek ini di lingkungan lokal Anda:

### 1. Prerequisites
Pastikan di dalam perangkat sudah terinstal:
- PHP >= 8.2
- Composer
- XAMPP 
- Node.js & NPM

### 2. Kloning Repositori
Kloning proyek ini dari GitHub ke direktori lokal:
```bash
git clone https://github.com/sonicmortis/tugas-laravel-authentication-dan-breeze
cd auth-demo
